# Raw Dataset Repository & Ingestion Source

This project uses the official, live food and fuel price time-series dataset for Yemen collected by the **United Nations World Food Programme (WFP)** and hosted on the **Humanitarian Data Exchange (HDX)**.

## Dataset Details
* **Dataset Title:** Yemen - Food Prices
* **Organization:** United Nations World Food Programme (WFP)
* **Landing Page:** [Humanitarian Data Exchange (HDX) - Yemen Food Prices](https://data.humdata.org/dataset/wfp-food-prices-for-yemen)
* **Direct Download URL:** `https://data.humdata.org/dataset/98574e10-6866-4f13-a2b1-3c8312801af5/resource/2f0c1d18-d42d-4e43-b928-1bd1fc7f6c90/download/wfp_food_prices_yem.csv`
* **Alternate Mirror:** `https://data.humdata.org/dataset/07137f6a-4d74-4b5a-93e5-3c0765c71d60/resource/35a09e02-4d56-42d9-a790-ee814fe4f738/download/wfp_food_prices_yem.csv`
* **File Name:** `wfp_food_prices_yem.csv`
* **Temporal Range:** March 15, 2009 – Present (monthly observations)
* **Total Records:** 60,000+ rows across 22 governorates and 28 regional markets.
